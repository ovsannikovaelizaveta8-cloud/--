# Аннотация

Настоящий документ является руководством пользователя по эксплуатации информационной системы **«Управление гостиницей»**. Данное руководство содержит информацию о назначении системы, установке и основных операциях.

Настоящий документ разработан в соответствии с ГОСТ 34 РД 50-34.698-90 «Автоматизированные системы. Требования к содержанию документов» и ГОСТ 19 «Единая система программной документации (ЕСПД)».

# Введение

Информационная система «Управление гостиницей» представляет собой клиент-серверное приложение для автоматизации работы отеля. 

Основные возможности программы:
- Авторизация и регистрация сотрудников с разграничением прав доступа.
- Управление номерным фондом.
- Бронирование номеров и регистрация заездов/выездов.
- Учет оплаты и выставление счетов.
- Быстрый поиск гостя по фамилии.
- Формирование отчетов (загрузка, выручка).

---

# Назначение и условия применения

Система предназначена для использования в гостиницах, отелях, хостелах. 

Условия применения:
- Операционная система: Windows 10/11 или Linux.
- Веб-браузер: Google Chrome, Яндекс.Браузер, Mozilla Firefox.
- Наличие локальной сети или доступа в Интернет.

# Описание операций

**Бронирование номера:**
1. Перейдите в раздел «Бронирования».
2. Нажмите кнопку «Новая бронь».
3. Выберите гостя из базы и номер.
4. Укажите даты заезда и выезда.
5. Нажмите кнопку «Сохранить».

*Пример SQL-запроса для проверки свободных номеров на выбранные даты:*

```sql
SELECT room_number, category, price
FROM Rooms
WHERE room_id NOT IN (
    SELECT room_id 
    FROM Bookings 
    WHERE (check_in_date <= '2026-12-05' AND check_out_date >= '2026-12-01')
);
```

<details>
  <summary>Нажмите, чтобы прочитать важное предупреждение (свернутая цитата)</summary>

> **Важно:** При попытке забронировать номер, который уже занят на эти даты, система выдает сообщение об ошибке и блокирует создание брони.
>
> > *Дочерняя цитата:* Проверка на пересечение дат реализована на уровне триггеров базы данных.

</details>

Настоящий документ является руководством пользователя по эксплуатации информационной системы **«Информационная система музыкальной школы»**. Данное руководство содержит информацию о назначении системы, установке и основных операциях. 

Настоящий документ разработан в соответствии с ГОСТ 34 РД 50-34.698-90 «Автоматизированные системы. Требования к содержанию документов» и ГОСТ 19 «Единая система программной документации (ЕСПД)». 

#### Введение

Информационная система «Информационная система музыкальной школы» представляет собой клиент-серверное приложение для автоматизации учебного процесса и учета успеваемости. 

Основные возможности программы: 

* Авторизация и регистрация пользователей с разграничением прав доступа (Гость, Учащийся, Преподаватель, Методист, Администратор).
* Ведение баз данных учащихся, преподавателей и учебных программ (6 направлений).
* Учет текущей успеваемости и результатов экзаменов.
* Быстрый поиск учащегося по фамилии.
* Формирование и экспорт аналитических отчетов (численность на начало года, отличники/хорошисты, неуспевающие, штат преподавателей).

#### Назначение и условия применения

Система предназначена для использования в детских музыкальных школах (ДМШ) и детских школах искусств (ДШИ). 

Условия применения: 

* Операционная система: Windows 10/11 или Linux.
* Веб-браузер: Google Chrome, Яндекс.Браузер, Mozilla Firefox.
* Наличие локальной сети или доступа в Интернет.

#### Описание операций

**Выставление оценки учащемуся:** 

1. Перейдите в раздел «Успеваемость и экзамены».
2. Выберите учащегося из выпадающего списка.
3. Укажите тип оценки (Текущая или Экзамен) и введите значение от 2 до 5.
4. Нажмите кнопку «Сохранить».

*Пример SQL-запроса для формирования отчета по отличникам:* 

sql

SELECT s.student_name, s.class_num, p.program_name
FROM Students s
JOIN Programs p ON s.program_id = p.program_id
JOIN Grades g ON s.student_id = g.student_id
GROUP BY s.student_id, s.student_name, s.class_num, p.program_name
HAVING MIN(g.grade_value) = 5 AND COUNT(g.grade_id) > 0;

Используйте код с осторожностью.
